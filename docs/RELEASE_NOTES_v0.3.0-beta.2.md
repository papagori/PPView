# PPView v0.3.0-beta.2

This focused beta update adds delayed, independent activity feedback for document opening, page rendering and preflight analysis. The indicators are non-blocking and disappear when their operation finishes, fails or is superseded. Existing preview, zoom and preflight behavior is preserved.

The installer and portable package use the same application build. This remains an unsigned beta; Windows SmartScreen may warn about an unfamiliar publisher. PPView inspects PDF-compatible content and does not validate Illustrator-native links or certify print production.
