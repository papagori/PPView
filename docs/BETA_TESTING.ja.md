# PPView 0.3.0-beta.2 テストチェックリスト

このベータ版では、PPView のローカルプレビューとプリフライト操作についてフィードバックをお願いします。PDF と `.ai` に含まれる PDF 互換表現を読み込みます。Illustrator 固有の編集情報やネイティブ画像リンクは検証せず、印刷品質を認証するものでもありません。

## お試しいただきたい内容

1. `PPView-Setup-v0.3.0-beta.2-x64.exe` をインストールし、スタートメニューから起動します。終了後、もう一度起動してください。任意でポータブル ZIP も展開して試せます。
2. 小さな PDF 互換 Illustrator ファイルと、大きな写真中心のファイルを開きます。PPView は元ファイルを変更しません。
3. 日本語テキストを含む文書と、ベクター図形・ラスター画像の両方がある文書を確認します。可能なら複数ページ PDF または複数アートボードの Illustrator ファイルも試します。
4. 表示される文字、写真、図形、ページ順を元のアプリと見比べます。プレビューだけで印刷適性が保証されるわけではありません。
5. ページに合わせる、幅に合わせる、ズーム操作、マウスホイール、パン、ページ移動、画像配置のハイライトを試します。画面の飛び、白紙、応答の遅れがあれば記録してください。
6. 画像 PPI、画像オブジェクト数と配置数、フォント埋め込み、ページボックス、カラーの結果を確認します。警告または「不明」が分かりにくい場合は記録してください。
7. 複数の文書を開き、解析中に切り替え、閉じて再度開きます。クラッシュ、エラー、メモリ使用量の異常な増加がないか確認します。

## 問題の報告

[GitHub Issues](https://github.com/papagori/PPView/issues) に PPView のバージョン（`0.3.0-beta.2`）、Windows のバージョン、問題の説明、再現手順、期待した結果と実際の結果を記載してください。スクリーンショットは任意です。非公開の画像は隠すか削除してください。

機密情報、顧客資料、非公開ドキュメントは添付しないでください。まずは説明、画面キャプチャ、ファイルのおおよそのサイズだけで十分です。ウイルス対策や Windows セキュリティ機能を無効にしないでください。
