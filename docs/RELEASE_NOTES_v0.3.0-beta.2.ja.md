# PPView v0.3.0-beta.2

この限定的なベータ更新では、ドキュメントを開くとき、ページを描画するとき、プリフライト解析中に、独立した遅延表示の状態インジケーターを追加しました。操作を妨げず、処理の完了、失敗、置き換え時に消えます。既存のプレビュー、ズーム、プリフライト動作は維持しています。

インストーラーとポータブル版は同じアプリケーションビルドから作成します。このベータ版には署名がなく、Windows SmartScreen が発行元を認識できないと警告する場合があります。PPView が検査するのは PDF 互換コンテンツであり、Illustrator ネイティブのリンク検証や印刷工程の認証は行いません。
