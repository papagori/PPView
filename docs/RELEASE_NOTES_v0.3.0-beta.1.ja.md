# PPView v0.3.0-beta.1

初めての外部ベータ候補です。機能を増やす更新ではなく、品質確認と配布の準備を行いました。Illustrator との全般的な互換性を保証するものではありません。

## v0.1.5 からの主な変更

- PDF プリフライトパネルを追加し、「確認済み」「警告」「エラー」「不明」を区別。
- 一意な画像オブジェクトと配置を区別し、取得可能な寸法、有効 PPI、ストリームの有無、デコード状態を表示。
- 画像配置のハイライト、フォント埋め込み情報、ページボックスと塗り足しの幾何情報、基本的なカラー空間情報を追加。
- ズーム中の即時拡大縮小、PDFium の最終描画のデバウンス、上限付きキャッシュ、描画サイズ制限を導入。
- オフラインのユーザーガイドと「PPView について」を翻訳し、Windows ユーザー単位インストーラーとポータブル版を追加。
- 承認済みのグラデーションヘッダーとコンパクトなフッターリンクを調整。
- 安定性診断、再現可能なテスト用 PDF、パッケージ確認、ベータテスト用チェックリストを追加。

## 対象範囲と制限

PPView は PDF または PDF 互換 `.ai` ファイル内の PDF 表現を検査します。Illustrator 固有の非公開構造やネイティブ画像リンク状態は確認せず、印刷会社ごとの出力を認証するものでもありません。取得できない情報は「不明」と表示されることがあります。画像の枠線は概算で、すべてのクリッピングパスを解決しません。インストーラーには署名がなく、SmartScreen が不明な発行元として警告する場合があります。非公開資料は手元に保管し、バグ報告に添付しないでください。

Python パッケージのバージョンは PEP 440 形式の `0.3.0b1`、アプリと配布ファイルでは `0.3.0-beta.1` と表示します。
