# PPView

PPView 0.3.0-beta.2 は、PDF および PDF 互換コンテンツを含む Adobe Illustrator `.ai` ファイルをプレビューする、独立したローカルデスクトップアプリです。Adobe ソフトウェア、サービス、アカウント、スクリプト API は不要です。PDFium でページを描画し、限定した技術的なプリフライト情報を表示します。ソースファイルの編集や修復は行いません。認証済みの印刷工程検証ツールではありません。

**元のドキュメントは変更されません。** ファイル処理はローカルで行い、アカウント、テレメトリー、クラウド処理、アップロード機能はありません。

## プリフライトチェック

「情報 / チェック」パネルにドキュメント、画像、フォント、ページジオメトリ、カラーの結果を表示します。解析はバックグラウンドで動き、プレビュー操作は続けられます。画像配置を選択すると該当ページへ移動し、座標を信頼できる場合は配置の概算範囲を一時的に囲みます。PDF ソースには注釈を加えません。

- **ドキュメント:** QPDF の構造アクセス、ページ数、コンテンツストリームの解析、PDFium 描画を個別に表示します。あるストリームの解析に失敗しても、取得できた他の結果は表示されます。
- **画像:** ネストした Form XObject を含む `Do` 配置を追跡し、ピクセル寸法、オブジェクト参照、カラー空間、ビット深度、配置寸法、水平・垂直・有効 PPI を表示します。PPI は配置変換から計算し、せん断では保守的な主軸スケールを使います。一意な PDF 画像オブジェクト数と配置数を区別します。同じオブジェクトを 2 回使う場合、オブジェクト 1 個、配置 2 件です。内部ストリームデータの有無とデコード状態は別々に報告し、デコード成功・失敗・メモリ制限による省略・不明を区別します。ページ描画の成功は、各画像ストリームのデコード成功を意味しません。外部ファイル参照は依存関係の可能性として表示します。配置の一時枠線は概算で、クリッピングパスは解析しないため、可視境界の保証ではありません。
- **Illustrator ファイル:** アクセス可能な PDF 互換表現のみを検査します。PDF 内で画像データを確認できても、Illustrator ネイティブ文書でリンクか埋め込みかは証明できず、その状態は未確認です。
- **解像度しきい値:** ファイル > プリフライト設定で 150、200、300 PPI を選択できます（初期値 300）。選択値未満は警告、150 PPI 未満は優先度の高い警告です。これはユーザーが選ぶ目安で、すべての印刷会社に共通する仕様ではありません。低解像度だけで印刷不可とは判断しません。
- **フォント:** PDF のフォントリソースに埋め込みプログラムの参照があるか調べます。日本語などの複合 CID フォントにも対応します。Type 3 フォントや読み取れない構造は「不明」になる場合があります。埋め込み参照があっても各グリフの表示が正しいとは限らず、テキスト抽出の成功も字形の正しさを保証しません。アウトライン化された図形をフォント不足とは扱いません。
- **ページジオメトリ:** MediaBox、CropBox、TrimBox、BleedBox、ArtBox の有効な寸法を mm で表示します。ドキュメント全体の寸法（MediaBox）と仕上がり寸法（TrimBox）は異なる場合があります。塗り足しの設定は 0、2、3、5 mm（初期値 3 mm）で、明示的に定義された TrimBox と BleedBox の幾何学的な差だけを比較します。描画内容が塗り足し端まで存在することは証明しません。ボックス情報がない、または曖昧な場合は「不明」とし、塗り足し不足とは断定しません。
- **カラー:** 検出できる DeviceGray、DeviceRGB、DeviceCMYK、ICCBased などの基本情報を表示します。色変換、印刷機のカラーマネジメント全体、ICC プロファイルの正確性、特色、DeviceN、透明効果、オーバープリントは検証しません。RGB を自動的にエラーとはしません。
- **不明:** 構造、画像デコード、変換行列、カラー空間を確実に特定できない場合に表示します。「不明」を「確認済み」として扱いません。

ファイルを開いたりプレビューできたりしても、印刷可能とは限りません。複雑な透明効果、特色、オーバープリント、画像クリッピング、詳細な問題位置のハイライト、印刷会社固有プロファイルは対象外です。Illustrator 対応は `.ai` 内の PDF 表現に限られ、編集可能な Illustrator 文書と異なる場合があります。PDF のページ数とアートボード数が一致するとも限りません。

## 使い方

ドラッグ＆ドロップ、**ファイル > ファイルを開く** / **Ctrl+O**、または内蔵ブラウザーから開きます。「情報 / チェック」パネルに結果を表示します。ツールバーでページ調整、ズーム、移動、ページ移動を行い、複数ドキュメントを開いたまま切り替えられます。英語、日本語、フランス語をすぐに切り替えられ、選択言語を保存します。

## オフラインヘルプとズーム

ヘルプメニューに、英語・日本語・フランス語のユーザーガイドと PPView についてを追加しました。ガイドはオフラインで利用できます。ズーム操作中は直前の PDFium 画像をすぐに Qt で拡大縮小し、150 ms の操作停止後に PDFium で高品質の最終画像を描画します。最終描画までは一時画像が粗く見える場合があります。元データのキャッシュはパスと更新時刻で管理し、上限 96 MiB、ドキュメントを閉じると解放します。PDFium ビットマップは最大 1,600 万画素、辺の長さ 16,384 ピクセルまでです。解像度を下げた場合は画面に明示します。ネイティブオブジェクトをスレッド間で共有しないよう、PDFium ドキュメントは描画ごとに開閉します。

`python scripts/zoom_benchmark.py --output dist/zoom-benchmark.json` で小型・複雑な合成 PDF の再現可能な計測を行えます。v0.2.2 描画処理と v0.2.3 キャッシュ処理、ズーム応答、描画回数、Windows メモリー使用量を比較します。実際の 29 MB Illustrator 文書での計測ではありません。

## ソースから実行

Python 3.11 以降が必要です。再現可能な Windows ビルドは 64-bit CPython 3.11.5 と `requirements-lock.txt` の固定バージョンを使用します。

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .[dev]
python -m ppview.main
python -m pytest
```

テストでは画像の拡大縮小・回転、Form XObject、フォントリソース、ページボックス、基本カラー空間を含む PDF を生成します。いずれも合成データで、実際の Illustrator ファイル全般との互換性を証明するものではありません。

## Windows インストーラーとポータブル版

Windows 10/11 x64 では `PPView-Setup-v0.3.0-beta.2-x64.exe` を実行するとユーザー単位でインストールできます。インストール先とインストーラーの言語（英語、日本語、フランス語）を選び、必要ならデスクトップショートカットを有効にします。スタートメニューのショートカットと Windows のアンインストール登録を作成します。`.ai` と `.pdf` の関連付けは変更しません。アンインストールは **設定 > アプリ > インストールされているアプリ** から行えます。ユーザー設定は保持されます。

インストーラーにはデジタル署名がありません。Windows SmartScreen が未知のアプリとして警告する場合があります。配布物に含まれる SHA-256 チェックサムを確認してください。

ポータブル版は `PPView-Portable-v0.3.0-beta.2-x64.zip` です。書き込み可能な場所に展開し、`PPView/PPView.exe` を起動してください。インストールも Python も不要です。設定は Windows ユーザープロファイルに保存されます。

[実際の Illustrator ファイルでの確認手順](docs/REAL_AI_VALIDATION.md)を参照してください。

## Windows 配布物をソースからビルド

```powershell
./scripts/build_windows.ps1
```

スクリプトは `.venv` を再作成してテストとスモークチェックを実行し、同じアプリビルドからポータブル ZIP と Inno Setup インストーラーを作成します。インストール、上書きインストール、アンインストールも確認します。GitHub Actions は ZIP、インストーラー、SHA-256 をワークフロー成果物として保存し、リリースは自動公開しません。

## PDFium の診断情報

`python scripts/pdfium_diagnostics.py` で import、pytest、faulthandler、描画を個別に比較できます。現在の観察結果と制約は[PDFium 調査記録](docs/PDFIUM_INVESTIGATION.md)にあります。この例外は未解決のため、公開ベータ前にクリーンな Windows 環境でも確認してください。


実装判断と再現可能な合成データの計測値は[ズーム性能の記録](docs/ZOOM_PERFORMANCE.md)を参照してください。
